# Class Scheduling Website & AI Chatbot 

A comprehensive web-based course scheduling system integrated with an AI Chatbot to assist university students in managing their timetables efficiently.

##  Overview
This platform helps students filter courses (major, general education, electives), generate timetables, and answer basic inquiries via an AI chatbot. It features a seamless integration with the university's REG API.

##  Tech Stack
* **Front-end:** JavaScript, React.js / Next.js
* **Back-end & Database:** Node.js, SQL
* **AI Integration:** Prompt Engineering & Chatbot APIs

##  Key Features
* **Smart Course Scheduling:** Filter subjects and generate customized study plans.
* **AI Chatbot Assistant:** Answers student queries regarding schedules and academics.
* **API Integration:** Connects directly with the university's registration system (REG API).
* **User Profiles:** Supports personalized settings and profile picture uploads.
